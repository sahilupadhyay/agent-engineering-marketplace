# Security Policy

## Supported versions

Until a tagged `1.0` release exists, only the default branch (`main`) is a
supported security target.

## Reporting a vulnerability

Report security issues through GitHub **private vulnerability reporting**
(the repository **Security** tab → **Report a vulnerability**).

Do **not** open a public issue for secrets, vulnerabilities, or other
security-sensitive findings.

This is a personal repository. Maintainer response is best-effort.

After this file lands on `main`, the maintainer must enable **Private
vulnerability reporting** in repository settings. That toggle cannot be
committed as a file.
