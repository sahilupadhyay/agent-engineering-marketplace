# Architecture intake

## Questions
- Goal, constraints, SLAs, and non-goals.
- Existing systems touched; build vs integrate decisions.

## Artifacts
1. Context diagram (boxes and arrows, not detail).
2. Key interfaces and data stores.
3. Failure modes and operational concerns.
4. Rollout and migration strategy.

## Exit
- Open decisions list with owners.
- Smallest shippable slice; defer nice-to-haves explicitly.
