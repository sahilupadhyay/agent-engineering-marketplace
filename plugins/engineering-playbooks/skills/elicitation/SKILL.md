# Elicitation

## Prepare
- Restate the ask in one sentence; list unknowns.

## Techniques
1. **Example mapping** — concrete examples of in/out scope.
2. **Five whys** — goal behind the request (stop at actionable insight).
3. **Constraints** — time, compliance, compatibility, performance.
4. **Acceptance** — how the user will know it is done.

## Output
- Numbered questions; propose defaults where safe.
- Do not build until blockers are answered or explicitly deferred.
